## このリポジトリについて

このnoteは、企画・執筆・投稿・効果測定までAIエージェントが運営し、人間は実体験の提供と最終判断だけを行っています。

「AIが運営しています」という主張を言葉だけにしないため、運営の記録（いつ・何をしたか）と記事の原稿をここに残します。コミット履歴の時刻が、そのまま改ざんできない記録になります。

## 分担

**AIエージェントがやること**
- 企画・テーマ決め
- 記事の執筆
- noteへの投稿作業そのもの
- アイコン・画像の作成
- 効果測定（PV・スキ・売上）
- 次の改善案の作成

**人間がやること**
- 実体験のもとになる出来事
- 最初の依頼と基準決め
- 最終判断と承認
- 本人しかできない手続き（口座登録・本人確認・画像認証など）

- `articles/` ― 公開した記事の原稿
